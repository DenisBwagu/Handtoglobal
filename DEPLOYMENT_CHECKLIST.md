# HandToGlobal Ubuntu 22.04 Deployment Checklist

## Before Deploy

- DNS `A` records for the root domain and `www` point to the VPS public IP.
- The repository is clean and the latest deployment commit is on the VPS.
- `database_required_tables.sql` is present.
- Production values are ready: `DOMAIN`, `DB_NAME`, `DB_USER`, `DB_PASS`, `ADMIN_EMAIL`.
- No production secrets are committed to Git.

## Server Packages

- Ubuntu 22.04 is updated.
- Nginx is installed and enabled.
- MySQL is installed and enabled.
- PHP 8.2-FPM is installed and enabled.
- Required PHP extensions are installed: `mysql`, `mbstring`, `xml`, `curl`, `zip`, `gd`, `intl`.
- Certbot and `python3-certbot-nginx` are installed.

## Application Config

- Nginx passes `APP_ENV=production`.
- Nginx passes `HTG_DEBUG=0`.
- Nginx passes `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, and `DB_PASS` through `fastcgi_param`.
- Production does not enable `HTG_CREATE_DEFAULT_ADMIN`.
- A real admin account is created with a unique password before first admin login.
- Public redirects do not depend on `localhost` or `/handtoglobal`.

## Files And Permissions

- App root is `/var/www/handtoglobal` or the chosen `APP_ROOT`.
- Source files are owned by `deploy:www-data`.
- Directories are `755`.
- Files are `644`.
- Only `uploads/` and `tmp_sessions/` are writable by `www-data`.
- `uploads/tasks/` exists and is writable.
- `uploads/settings/` exists and is writable.
- Existing app files are backed up before rsync overwrite.
- `uploads/` and `tmp_sessions/` are excluded from rsync deletion.

## Nginx

- Server block is installed from `deployment/nginx-handtoglobal.conf` or generated by `deploy_ubuntu_22_04.sh`.
- `root` points to the project directory.
- PHP uses `/run/php/php8.2-fpm.sock`.
- Upload PHP execution is blocked.
- Dotfiles are blocked.
- setup, repair, debug, test, backup, and diagnostic scripts are blocked.
- `nginx -t` passes.

## Database

- MySQL database exists with `utf8mb4`.
- MySQL user exists and has privileges only for the app database.
- `database_required_tables.sql` has been imported.
- Existing production data is backed up before any import or migration.

## SSL

- Certbot certificate is issued for the root domain and `www`.
- Nginx redirects HTTP to HTTPS.
- `systemctl list-timers` shows Certbot renewal timer.

## Post-Deploy Smoke Test

- `/` loads over HTTPS.
- `/login.php` loads over HTTPS.
- User login redirects to `dashboard.php`.
- Admin login redirects to `admin/dashboard.php`.
- User logout clears session and returns to login.
- Admin logout clears session and returns to login.
- Admin settings image upload writes to `uploads/settings/`.
- Admin task image upload writes to `uploads/tasks/`.
- Withdrawal request flow loads and saves.
- Combo create/edit saves without missing-column errors.
- Nginx and PHP-FPM logs have no new fatal errors.
